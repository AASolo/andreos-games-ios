# Andreos Play для iPhone

Все игры Andreos в одном приложении для iPhone и iPad:

- Дорога в океан
- Бутербашня
- Кимчи-кафе Глеба Ли
- HackQuest

## Как установить

1. Открой **https://aasolo.github.io/andreos-games-ios/** в Safari на iPhone.
2. Нажми «Поделиться» (или меню ⋯) → **«На экран „Домой“»** → «Добавить».
3. На экране появится иконка Andreos Play. Приложение открывается на весь экран, без адресной строки.

После первого запуска все игры (и Python для HackQuest) сохраняются на телефоне и работают без интернета.
Обновления приходят сами: когда выйдет новая версия, в приложении появится кнопка «Обновить».

## Что внутри

Всё как в Android-версии: живой фон, заставка, «Игра дня» и «Продолжить», избранное и фильтры,
статистика времени и серий 🔥, 9 достижений с конфетти, спокойная фоновая музыка в меню, лёгкий отклик при нажатиях (iOS 18+), звуки,
кнопка «Домой» поверх игры (её можно перетащить в любой угол). Подстраивается под любой экран,
вертикально и горизонтально, с учётом чёлки и Dynamic Island.

## Как это устроено

- `src/` — меню (index.html, app.css, app.js), офлайн-режим (`sw.js`), кнопка «Домой» в играх (`game-shell.js`), иконки.
- `scripts/build.sh` — собирает сайт в `dist/`: скачивает свежие версии игр из их репозиториев,
  кладёт рядом three.js и Pyodide и составляет список файлов для офлайна.
- `.github/workflows/pages.yml` — при каждом пуше в `main` и раз в день сам собирает и публикует приложение на GitHub Pages.

Чтобы подтянуть изменения в играх сразу: Actions → «Публикация на GitHub Pages» → Run workflow.

### Добавить новую игру

1. Добавь имя репозитория в список `GAMES` в `scripts/build.sh`.
2. Добавь карточку в массив `games` в `src/app.js`.
